# Iris literature review

The main editable manuscript is **Iris_Literature_Review.tex**. It is standalone: its numbered bibliography and tables are embedded, and it requires no external images or bibliography file. It uses the IEEEtran journal class. Open it in Codex's LaTeX editor, or compile it twice with pdfLaTeX in a normal TeX environment that includes IEEEtran.

The paper lists Eklavya Nathani, Manit Bisht, and Anis Fatema. No institutional affiliation has been added. Its scope is a focused narrative review of gaze, visual feedback, and freshness in low-cost companions, with Iris as an illustrative implementation.

Supporting files:

- evidence.json is the source ledger, including access levels and passage locations.
- evidence.md presents the same ledger as a readable comparison.
- search-log.md records actual discovery and retrieval actions.
- brief.md records scope and the writing/format guidance.
- review.md is the checked working-text copy, using citation keys for the local audit.
- qa.md records verification and remaining author-level submission details.

The evidence-gap table in the manuscript explains what research would resolve each uncertainty and how the outcome would help design Iris. Adequate material exists for this review; no miniature-display observer experiment, end-to-end timing benchmark, or sustained-use outcome is claimed.
